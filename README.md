# Shalost FOTUR

Локальное Windows-приложение для работы с подключёнными аккаунтами Pulse РТУ МИРЭА: вход через официальный сайт, поиск QR-кодов и отправка подтверждения присутствия.

> Проект не связан с РТУ МИРЭА и Pulse. Используйте его только для собственного аккаунта и в соответствии с правилами учебного заведения.

## Что делает приложение

- Главный интерфейс запускается сразу и не зависит от загрузки Pulse.
- Вход выполняется в обычном окне официального Google Chrome, включая 2FA.
- Для каждого аккаунта сохраняется отдельный локальный профиль Chrome.
- На главной показано количество подключённых аккаунтов, управление ими находится в настройках.
- QR-коды Pulse ищутся на всех экранах раз в 2 секунды.
- С помощью расширения Chrome можно подключить одну вкладку для поиска QR, в том числе после переключения на другую вкладку.
- Каждый найденный QR отправляется всем добавленным аккаунтам, результат каждого виден в журнале.
- Окно «Контроль присутствия» в MTS Link распознаётся на экране или на подключённой вкладке; приложение пытается нажать «ПОДТВЕРЖДАЮ» раз в 2 секунды. Исчезновение окна фиксируется в журнале.
- Для трёх разных QR выполняются успешные подтверждения подряд. После третьего действует настраиваемая пауза, по умолчанию 10 минут. Повтор уже подтверждённого QR не засчитывается. Пауза не влияет на MTS Link.
- Понятный журнал остаётся в окне, полный технический журнал сохраняется в доступной для записи папке.
- В настройках доступны добавление и удаление аккаунтов, путь к их профилям, открытие папки и копирование пути.
- Добавлены ссылки на FOTUR VPN и CloudTips QR.

## Установка и первый вход

Нужен Windows 10/11 и установленный Google Chrome.

1. Скачайте сборку из Releases:
   - Shalost-FOTUR-Setup-…exe — установщик с ярлыком;
   - Shalost-FOTUR-portable.zip — portable-вариант. Распакуйте архив целиком и запустите Shalost-FOTUR.exe.
2. Откройте приложение. Главный экран должен появиться сразу.
3. Откройте «Управление аккаунтами» и нажмите «Добавить аккаунт». Откроется отдельное официальное окно Chrome.
4. Войдите обычным способом и завершите 2FA. После обнаружения входа окно Chrome закроется, а аккаунт появится в списке.
5. Нажмите «Начать сканирование». Кнопка станет кнопкой остановки.

Cookie вручную копировать не нужно. Если Chrome или Pulse вернул ошибку, откройте нижний журнал: статус и причина остаются видны, а поиск QR продолжится.

## Сессия и приватность

Сессии хранятся в отдельных профилях Chrome:

    %LOCALAPPDATA%\Shalost\profiles

Существующий профиль `%LOCALAPPDATA%\Shalost\pulse-chrome-profile` сохраняется и добавляется автоматически после успешной проверки. Не передавайте содержимое папок: в них находятся данные авторизации. Удаление выбранного аккаунта удаляет его профиль. Срок жизни сессии определяется сервером Pulse; приложение не может его продлить.

## Фоновая вкладка Chrome

Расширение требует Chrome версии 116 или новее. В настройках приложения нажмите «Открыть папку расширения». Откройте в Chrome страницу `chrome://extensions`, включите режим разработчика и выберите «Загрузить распакованное расширение», указав открывшуюся папку. Закрепите расширение на панели браузера.

Откройте вкладку с трансляцией, скопируйте ключ в настройках приложения, нажмите значок расширения, вставьте ключ и выберите «Подключить вкладку». Затем можно переключиться на другую вкладку. При повторном запуске приложения ключ меняется, поэтому вкладку нужно подключить заново. Для отключения нажмите «Остановить» в расширении.

Приложение получает кадры только выбранной вкладки через локальное соединение и пытается нажать кнопку контроля присутствия на странице `my.mts-link.ru`, даже если вкладка переключена или окно свёрнуто. Исчезновение окна после нажатия не является подтверждением ответа сервера. Работа зависит от разметки MTS Link и поведения Chrome; если страница не принимает программное нажатие или Chrome не обновляет изображение, подтверждение нужно выполнить вручную. Приложение не подключается автоматически к произвольным фоновым вкладкам.

## Логи

В интерфейсе выводятся только рабочие события UI, AUTH, SCAN и PULSE. Полная диагностика сохраняется в файле `pulseqr.log`:

- в portable-версии — рядом с `Shalost-FOTUR.exe`;
- в установленной версии — в `%LOCALAPPDATA%\Shalost\pulseqr.log`.

Это позволяет не засорять экран техническими ошибками, но сохраняет данные для отладки. Установленная версия не пытается записывать журналы в `Program Files`.

## Сборка из исходников

Требуется Python 3.11+ и Google Chrome.

    python -m pip install -r requirements.txt pyinstaller
    pyinstaller --noconfirm --clean --onedir --windowed --exclude-module numpy --icon assets/shalost-fotur.ico --add-data "assets/cloudtips-donation-qr.png;assets" --add-data "assets/shalost-fotur.ico;assets" --add-data "assets/shalost-fotur.png;assets" --add-data "extension;extension" --name Shalost-FOTUR main.py

Готовая portable-папка появится в dist\Shalost-FOTUR. Сценарий GitHub Actions автоматически создаёт и portable ZIP, и обычный установщик после push тега вида v0.1.0.

## Проверка перед релизом

Запустите `python -m unittest discover -s tests -v`, затем `python main.py`. Добавьте свои аккаунты через настройки, завершите 2FA, закройте и снова откройте программу и проверьте список аккаунтов. Сначала проверьте сканирование видимого QR и результат отдельно для каждого аккаунта. После трёх разных успешных QR должна начаться пауза; управление аккаунтами во время сканирования заблокировано.

Чтобы проверить фоновый режим, установите расширение и подключите вкладку с трансляцией по инструкции выше, запустите сканирование, переключите вкладку, затем отдельно проверьте свёрнутое окно. Проверьте как QR, так и контроль присутствия, сверив результат в самом Pulse или MTS Link. Локальная страница `presence-demo.html` подходит для проверки видимого экранного распознавания; она не является реальной страницей MTS Link и не проверяет нажатие расширения. После остановки сканирования нажатия выполняться не должны. Проверьте также удаление выбранного тестового аккаунта, перезапуск и отсутствие процесса после закрытия программы.
