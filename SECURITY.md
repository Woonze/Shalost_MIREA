# Безопасность

Не публикуйте в issue, pull request или логе:

- Cookie и содержимое профиля Pulse;
- API-ключи и другие секреты;
- пароли, коды 2FA и персональные данные;
- файлы из %LOCALAPPDATA%\Shalost\profile.

Если вы нашли уязвимость, не публикуйте детали в открытом issue. Свяжитесь с владельцем проекта через [GitHub-профиль Woonze](https://github.com/Woonze).
