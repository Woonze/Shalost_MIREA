# Как внести вклад

Спасибо за интерес к Shalost FOTUR.

1. Создайте отдельную ветку для изменения.
2. Не добавляйте Cookie, API-ключи, файлы профиля Pulse, журналы или собранные EXE.
3. Перед pull request выполните:

       python -m py_compile main.py

4. Кратко опишите, что изменилось и как это проверено.

Для крупных изменений сначала создайте issue с предложением.
